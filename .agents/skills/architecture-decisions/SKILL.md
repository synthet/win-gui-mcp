# architecture decisions

Follow the project's existing ADR location, numbering and status convention. Inspect prior decisions and relevant code before choosing a title or number.
Record context and constraints, considered alternatives, decision and reasons, consequences, evidence, and status. Distinguish accepted decisions from proposals. Link superseding decisions rather than silently rewriting history.
Use the documented local tooling when available; do not assume a project-specific MCP command exists. Report the created record and unresolved tradeoffs.


Resolve helper paths from this skill directory. Run project commands from the target workspace.
